# ZUNO Play expansion · 15 November 2026

Eight original browser-local game tracks: Number Galaxy, Pattern Planet, Word Workshop, Safari ya Maneno, Crossword Cove, Memory Orbit, Rover Routes, Discovery Quest. Each offers 100 reproducible practice levels in each of three reading bands (2,400 editions). These are programmed practice sets, not 2,400 individually authored lessons. English and Kiswahili use starter vocabulary banks; discovery combines 50 additional original questions in five topic families with the existing age-specific questions. Terms describe repetition honestly. Educator review and broader authored content remain needed.

Maths covers arithmetic, sharing, missing values, time and perimeter for younger learners; fractions, decimals, percentages, multiplication/division for middle; signed values, equations, ratio, probability, powers and area for older learners. Pattern chapters vary arithmetic, alternating, growing and letter rules. Crosswords generate valid connected word placements. Memory uses paired 3D symbols. Rover boards preserve a reachable path and introduce blocks.

No generation API or runtime download is needed. Best stars are saved locally by age/game/level; points derive from best stars and cannot be farmed by replay. Every chapter displays ten nodes, with all chapters selectable. Nothing is gated by payment, lost lives or timed pressure. Milestone badges are deterministic completion markers, not loot boxes.

Design: approved Sora/Jakarta and ZUNO identity; saturated chapter accents, raised nodes and buttons, 48 original 3D icons across two atlases, clear text/surface token pairs. Bottom navigation is hidden during games, policy pages, readers and interactive world details on mobile. Games also hide desktop navigation for focus, with explicit exit-to-path controls. Chat composer notes moved to four policy pages. History dialog toolbar reserves space for its separate close control.

Feedback: worded correct/learning states, symbol and colour, optional synthesized sound (off initially), supported-browser short vibration with an off switch, bounded Canvas Confetti celebration. Reduced motion suppresses confetti and decorative feedback. iPhone Safari web vibration is not promised. Preloader shows only while actual module loading takes place; no fake wait.

## Research and reuse
- Duolingo official path explanation: https://blog.duolingo.com/new-duolingo-home-screen-design/ — small units, recurring practice, clear path. Used as strategy only; no artwork or code copied.
- Canvas Confetti 1.9.4: https://github.com/catdad/canvas-confetti — downloaded pinned browser bundle; ISC notice retained locally and linked in acknowledgements. `disableForReducedMotion` enabled. No third-party network call for animation.
- Exolve: https://github.com/viresh-ratnakar/exolve — evaluated established crossword player; not bundled, because a compact original grid fits this app's starter puzzles better.
- MDN vibration: https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate — limited browser support, user activation required; visual fallback always available.
- ODPC official laws and children's guidance informed the policy drafts. Policies do not certify compliance. Exact operator identity, processor retention and production parental-consent procedures still require verification.

## Material boundaries
Connected chat, reader explanations and optional question-game hints now share a dedicated Clerky endpoint. It uses actual free-provider catalogs, citations, automated input/output checks and server-side quotas. Activation is explicitly a grown-up testing preview, not verified child consent. Excluded camera, live voice and AI-assisted creation remain absent. Existing fail-closed server adapter tests are retained. Site is still a development preview, not an independently reviewed child-account launch.

Live synthetic QA: Groq gpt-oss-20b returned a grounded, cited Mars explanation after request classification and answer review. OpenRouter uses Clerky’s centrally saved connection and permits only explicit zero-price `:free` models with zero-retention endpoints; availability is not guaranteed. No provider keys are included in ZUNO assets.
